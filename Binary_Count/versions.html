Terminal Klash Versions

An RPG Game Built by Myself. Some notes:

  • I'm an intermediate Python Developer, so please don't judge me.
  • This is free and open-source so you can change it :3
  1. binary_count.py- the original binary counter
  2. nested_nyalist.py- the nested codename generator that uses a few of my things in life
  3. v2.py- the more controllable Binary Counter
  4. v3.py- Introducing the Ternary Counter!

    5. Next, follow these steps:

    1. Open the link
    2. Copy the Code
    3. Right-Click on Windows Explorer and create a new file (preferably NotePad)
    4. Install Python by opening up this link and install the latest version of Python. Follow the steps to install it.
    5. Paste the code in the file
    6. Save as a .py file
    7. Run the file by double-clicking it or preferably, opening terminal and type in the filename of the Python File.
